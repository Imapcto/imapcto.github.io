Exclusão de dados

Sem conta de jogador

Esta versão não cria contas nem armazena dados de jogadores em um banco de dados remoto. Por isso, não existe uma conta de jogo para excluir no servidor.

Apagar dados no Android

  1. Abra Configurações do celular.
  2. Entre em Aplicativos e escolha IL Impacto Jogo.
  3. Abra Armazenamento e selecione Limpar dados.
  4. Para remover o aplicativo, escolha Desinstalar.

No navegador

Apague os dados do site nas configurações do navegador. Arquivos que você baixou devem ser excluídos separadamente da pasta Downloads.
